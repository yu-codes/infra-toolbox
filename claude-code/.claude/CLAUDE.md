# 全域偏好設定

## 語言與溝通

- 使用繁體中文回覆
- 註解使用英文
- Commit message 使用英文 Conventional Commits 格式，如 `feat:`, `fix:`, `refactor:`, `docs:`, `chore:`

## 工作原則

- **先講清楚假設**：不確定就先問，不要自己猜測後直接動手
- **不要過度工程化**：能簡單解決就不加戲，只做被要求的事
- **不碰無關範圍**：修 bug 就修那個 bug，不要順手重構全世界
- **做完必須驗證**：跑測試、看實際結果，確認真的可用才算完成
- **不主動生成文件**：沒有明確指令要求時，不要自行產生開發文件（README、設計文件等）

## 編碼風格

- 優先使用標準庫，避免不必要的依賴

## 安全原則

- 永遠不要讀取或輸出 `.env`、`*.key`、`*.pem`、`credentials*` 等機密檔案
- 永遠不要硬編碼密鑰、token、密碼（也不要寫進 commit 訊息）
- 敏感資訊存環境變數或 `.env`
- 遵循 OWASP Top 10
- 所有外部輸入必須驗證
